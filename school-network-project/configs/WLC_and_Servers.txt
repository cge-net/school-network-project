WIRELESS > All APs > (each AP)
  AP Mode       : FlexConnect
  FlexConnect   : VLAN Support enabled, Native VLAN 10
  AP switchport : trunk, native 10, allowed 10,20,30,40 (see access switch configs)
  APs find the WLC through DHCP option 43 (Management_Pool "WLC Address" 10.1.10.4).
  After changing the WLC IP, power-cycle the APs so they relearn it.

Packet Tracer limitations (document, don't "fix"):
  - Management traffic is untagged -> switch port uses native VLAN 10.
  - Switch receives BPDUs on the controller port (a real WLC sends none)
    -> switch port uses bpdufilter.
  - Central switching does not tag client VLANs -> FlexConnect local switching used.
  - NTP pages unsupported -> clock set manually (COMMANDS > Set Time).
  - Summary page may show Management IP 0.0.0.0 / 192.168.1.1 (display bug).
